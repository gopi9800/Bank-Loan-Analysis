# Bank Loan Analysis — Power BI Dashboard

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze bank loan performance and provide a detailed view of loan applications, funded amounts, received amounts, loan quality, and borrower-related characteristics.

The dashboard is organized into three main views:

- **Summary** — Provides an overall view of loan applications, funded and received amounts, average interest rate, average DTI ratio, and good vs. bad loan performance.
- **Overview** — Analyzes loan applications across different dimensions such as loan status, loan term, employee length, loan purpose, and home ownership.
- **Details** — Provides loan-level records with information such as purpose, home ownership, grade, sub-grade, issue date, funded amount, interest rate, installment, and received amount.

## 🎯 Project Objectives

- Monitor overall loan application activity
- Analyze total funded and received amounts
- Compare good loans and bad loans
- Analyze loan status and performance
- Monitor average interest rate and DTI ratio
- Understand loan application trends over time
- Analyze applications by loan term
- Analyze applications by employee length
- Identify common loan purposes
- Analyze applications by home ownership
- Provide detailed loan-level information for further analysis

## 📊 Dashboard Sections

### 1. Summary

The Summary page provides a high-level view of the bank's loan portfolio through key performance indicators and loan-status analysis.

Key metrics include:

- Total Funded Amount
- Total Loan Applications
- Average Interest Rate
- Average DTI Ratio
- Total Received Amount
- Good Loan Applications
- Good Loan Funded Amount
- Good Loan Received Amount
- Bad Loan Applications
- Bad Loan Funded Amount
- Bad Loan Received Amount

The page also provides loan-status-level comparisons for Fully Paid, Charged Off, and Current loans. :contentReference[oaicite:0]{index=0}

### 2. Overview

The Overview page provides a deeper analysis of loan applications across different borrower and loan characteristics.

The analysis includes:

- Monthly loan application trends
- Loan applications by term
- Loan applications by employee length
- Loan applications by purpose
- Loan applications by home ownership
- Good vs. bad loan analysis
- Filtering by loan status, address state, purpose, and grade

These views help examine how loan applications are distributed across different loan and borrower characteristics. :contentReference[oaicite:1]{index=1}

### 3. Details

The Details page provides a detailed loan-level view of the underlying records.

The table includes fields such as:

- Loan ID
- Loan Purpose
- Home Ownership
- Grade
- Sub Grade
- Issue Date
- Total Funded Amount
- Interest Rate
- Installment
- Total Received Amount

This view allows individual loan records to be examined alongside their financial and classification attributes. :contentReference[oaicite:2]{index=2}
